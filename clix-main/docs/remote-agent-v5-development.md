# V5 开发文档：图片、代码索引与跨平台发布

状态：待开发。依赖前四版的连接、安全、会话和本地扩展能力。

## 交付目标

支持本地图片输入、本地项目代码索引，以及 Windows、macOS、Linux 的客户端安装和更新。服务器继续运行 Agent；不默认把整个项目上传服务器。

## 开发任务

1. **图片输入**：客户端处理现有 `image/` 识别、路径和大小校验，在用户提交后通过加密连接发送图片；服务器按实际模型能力决定是否可用。发送前向用户明确图片会传给服务器和模型供应商；错误、取消和超限不静默改为文本。
2. **代码索引**：索引文件和代码扫描默认在客户端项目范围内；先用精确的文件搜索工具，语义搜索仅用于模糊查找。明确向量生成的位置、模型服务、发送内容和配置方式；未经用户配置和明确启用，不批量上传代码生成索引。
3. **安装包**：为三个系统提供安装和卸载说明，确定是否捆绑 Java 运行环境。每种安装方式提供可执行的 `clix` 命令、版本查看、登录和更新；不依赖用户自行安装 Maven。
4. **版本兼容**：扩展 V1 协议版本协商；不兼容时提示对应升级方式，不悄悄降级安全检查。服务端升级期间，不得自动重放未确认的工具操作。
5. **发布验证**：每个平台测试路径、符号链接、中文、终端尺寸、确认按键、取消和命令运行。发布说明列出支持的系统、服务端要求、已知限制、数据传输范围和回退方式。

## 测试与完成条件

- 图片路径越界、格式不支持、过大、用户取消和模型不支持时明确报错；使用模拟服务验证传输，不调用真实模型。
- 索引只扫描允许的项目路径；未启用时不产生批量发送，向量或服务不可用时提示原因。
- 在三种系统上分别验证安装、登录、运行、更新、卸载、断线恢复及本地安全检查；测试记录标明系统版本。
- 回归 `image/`、`rag/`、工具、协议和渲染相关测试；不运行评测或 Docker。

完成标志：三个平台可安装并运行客户端；用户明确选择后能发送图片和使用代码索引，相关数据传输行为有文档且可验证。
